# Acceso a GridMind

En la pantalla inicial, crea una cuenta o inicia sesión. Cada operador tiene su propio inventario. En **Activos**, puedes cargar equipos de ejemplo o registrar tus transformadores.

Si aparece un mensaje solicitando HTTPS, abre la URL segura del proyecto y verifica que la dirección de la API también use HTTPS. Para pruebas locales se puede usar `http://localhost:5173`.

Si el registro está habilitado, el evaluador puede crear su cuenta y cargar su propio ejemplo.
