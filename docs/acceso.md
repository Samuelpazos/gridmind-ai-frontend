# Acceso a GridMind

En la pantalla inicial, **Entrar como administrador** abre un formulario para la cuenta autorizada. Después de validar la sesión, la aplicación abre **Activos**.

Si aparece un mensaje solicitando HTTPS, abre la URL segura del proyecto y verifica que la dirección de la API también use HTTPS. Para pruebas locales se puede usar `http://localhost:5173`.

Las credenciales se configuran en el backend. Comparte por privado el acceso de evaluación con la persona que vaya a revisar el proyecto.
