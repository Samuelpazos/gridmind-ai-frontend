# Administrar transformadores

Inicia sesión y abre **Activos**. Elige **Transformadores reales** o **Transformadores simulados** y pulsa **Agregar transformador**.

- Para un equipo real, indica el nombre y la subestación. Puedes completar la potencia y la antigüedad en **Datos técnicos opcionales**.
- Para un equipo simulado, elige un perfil. Cada perfil proporciona los datos de ejemplo y los sensores de prueba.
- En la cuenta propietaria del ESP32, abre **Pendiente de conexión** y vincula el código de temperatura.
- Usa el lápiz para cambiar el nombre. Usa **Archivar** para retirarlo del inventario activo o **Restaurar** para recuperarlo.
