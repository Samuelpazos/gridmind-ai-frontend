# Recorrido para la presentación

1. En **Resumen**, cambia de transformadores reales a simulados y compara los indicadores.
2. En **Activos**, abre las lecturas de un equipo para identificar el tipo y el origen de los datos.
3. En **Simulador**, ensaya una temperatura objetivo y explica cómo cambia el porcentaje estimado.
4. En **Información del Modelo**, abre el escenario de referencia y aclara que las métricas se calcularon con datos sintéticos.
5. En **Operaciones**, demuestra una acción reversible sobre un equipo de prueba y usa **Deshacer**.
