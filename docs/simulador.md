# Simular un escenario

Elige un grupo y un transformador. Selecciona una variable e introduce el valor final que quieres evaluar, por ejemplo, 90 °C. El valor también se puede ajustar con el deslizador.

El panel compara la lectura disponible y el valor simulado. Cada lado muestra su estado y el porcentaje de probabilidad estimado por el modelo. **Sin lectura** significa que no hay una lectura de referencia disponible.

El escenario se guarda en el historial del grupo seleccionado. Las lecturas operativas conservan sus valores originales.
